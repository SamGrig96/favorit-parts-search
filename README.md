# Подбор автозапчастей — тестовое задание (Favorit Parts)

Клиентское приложение на **React + Redux Toolkit** (JavaScript, без TypeScript) со стилизацией **Bootstrap 5** для работы с веб-сервисом «Проценка» Favorit Parts.

## Как работает

1. **Поиск производителей.** Пользователь вводит артикул — запрос уходит автоматически по факту ввода (debounce 500 мс, предыдущий запрос отменяется через `AbortController`). Показывается список производителей с наличием.
2. **Аналоги и предложения.** При выборе производителя выполняется запрос `number + brand + analogues=on`. В таблице — искомая деталь и все аналоги по складам: производитель, артикул, название, склад, **цена**, **остаток**, дата отгрузки.
   - Цена берётся со склада (`warehouses[].price`), как требует документация.
   - Фильтр «Только в наличии», сортировка: искомая деталь первой, затем по цене.

## Обработка состояний

- Лоадеры на обоих этапах.
- Ошибки API (`{"error": "..."}`), HTTP-ошибки, сбои сети, некорректный JSON — показываются с кнопкой «Повторить».
- Пустой ответ (API возвращает «пустую» структуру с нулевым `goodsID`) — сообщение «ничего не найдено».
- Защита от гонок: устаревшие ответы игнорируются.

## Структура

```
src/
  api/favoritApi.js        — запросы к API и нормализация ответов/ошибок
  store/searchSlice.js     — Redux slice + async thunks (этап 1 и 2)
  utils/offers.js          — преобразование товаров в предложения, форматирование
  components/
    SearchForm.jsx         — поле ввода артикула
    BrandList.jsx          — список производителей
    OffersTable.jsx        — таблица аналогов и предложений
    StatusView.jsx         — Loader / ErrorAlert / Empty
```

## Запуск

```bash
npm install
npm run dev
```

По умолчанию используется демо-ключ из документации. Для своего ключа скопируйте `.env.example` в `.env` и укажите `VITE_API_KEY`.

Сборка: `npm run build`. Тесты (Vitest + Testing Library): `npm test`. Артикулы для проверки: `01089`, `7160500039S`.
